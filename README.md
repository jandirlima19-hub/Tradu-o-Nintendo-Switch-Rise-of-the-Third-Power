# Tradu-o-Nintendo-Switch-Rise-of-the-Third-Power
Tradução para atmosphere do jogo Rise of the Third Power
Rise of the Third Power — Português brasileiro — Versão 4
Tradução feita por Jandir lima.
REVISÃO CONTEXTUAL
O roteiro dos eventos foi revisado em blocos completos, com as falas na
ordem das cenas. A revisão inclui gênero dos personagens, sentido,
humor, escolhas, menus, descrições, missões, habilidades e itens.
As correções de acentos e espaço das versões anteriores estão incluídas.

INSTALAÇÃO NO ATMOSPHERE
1. Feche o jogo completamente.
2. Extraia o arquivo e copie a pasta atmosphere de Pronto_para_SD para a raiz do cartão SD.
3. Mescle as pastas e substitua o arquivo data.unity3d anterior.
4. Abra o jogo usando o idioma inglês para jogar em português.
O arquivo deve ficar neste caminho:
SD:/atmosphere/contents/0100F05015052000/romfs/Data/data.unity3d

Compatibilidade: título 0100F05015052000 e atualização v327680.
